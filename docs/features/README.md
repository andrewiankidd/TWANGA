# Features

Per-feature documentation. Each page covers both the CLI and GUI surfaces
side by side — feature parity is a project invariant so it makes sense for
the docs to enforce it too.

| Feature | What it does |
|---------|--------------|
| [Tuner](tuner.md) | Live pitch detection vs your chosen tuning. |
| [Recorder](recorder.md) | Capture played notes as an alphaTex tab. |
| [Playback](playback.md) | Play a tab with metronome, wait mode, loop, transpose. |
| [Patterns](patterns.md) | Bundled rhythm + picking drills (clawhammer, rolls, strums, guitar fingerpicking). |
| [Tab editor](editor.md) | Post-capture cell-level edits to recordings. |
| [Tunings](tunings.md) | Built-in + user-defined tuning registry. |
| [Hardware](hardware.md) | Audio-input setup — mics, instrument cables, interfaces, latency. |

For a higher-level intro see the [CLI overview](../CLI.md) or
[GUI overview](../GUI.md). The per-flag CLI reference lives in
[crates/twanga-cli/README.md](../../crates/twanga-cli/README.md).
