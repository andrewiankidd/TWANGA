Each row shows your detected pitch against the target — the bar's cursor slides left if you're flat, right if you're sharp, centred when you're in tune (within ±5¢). Recorder

Live tab recorder. Pick a tuning, set the tempo grid, click Start recording, and play. Detected notes land in the current column at the matching string and fret — same pitch matching the CLI uses. Saved recordings live in the browser library; the toast on Save offers a one-click .alphatex download for safekeeping.

Browser storage warning. Recordings live in your browser's local storage, which can be cleared by the user or evicted by the browser. Click Download .alphatex on every recording you want to keep. The desktop app stores recordings on your filesystem and doesn't need this warning.

Tunings

Built-in presets ship with TWANGA. Your own custom tunings are stored locally in localStorage, mirroring the CLI's $CONFIG/twanga/tunings.toml. The Tuner picker draws from this same merged list, so anything you define here is immediately playable there.

Patterns

Bundled rhythm + picking drills. Each one is a short loop — lock in the groove without worrying about a tune. Tempo and metronome are on by default; lower the BPM until you can play it cleanly, then bring it back up.

Importer

Add a tab to your library. Accepts .alphatex (TWANGA native), .musicxml / .xml (open standard from MuseScore / Sibelius / Guitar Pro), .mxl (zipped MusicXML), .mid / .midi (Standard MIDI File), .abc (ABC notation — common in folk / traditional music), and .tab (ASCII tab, the plain-text format on most tab-sharing sites). All sources land as alphaTex in <data-root>/library/ after conversion.

Browser storage warning. In the browser build, imported tabs live in IndexedDB and can be evicted under storage pressure. The desktop app writes to ~/twanga/library/ on disk and doesn't need this warning.
