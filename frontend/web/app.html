Pick a tuning, click Start mic, and play any string. Each row shows your detected pitch against the target — the bar's cursor slides left if you're flat, right if you're sharp, centred when you're in tune (within ±5¢). Recorder

Live tab recorder. Pick a tuning, set the tempo grid, click Start recording, and play. Detected notes land in the current column at the matching string and fret — same pitch matching the CLI uses. Stop when done, then Save to download a .alphatex file that round-trips through twanga play.

Tunings

Built-in presets ship with TWANGA. Your own custom tunings are stored locally in localStorage, mirroring the CLI's $CONFIG/twanga/tunings.toml. The Tuner picker draws from this same merged list, so anything you define here is immediately playable there.
